# النسخ الاحتياطي المشفّر إلى وجهة ثانية — Posegypt

**الحالة:** تمت إضافة مسار برمجي للتصدير والتحقق من الاستعادة. يلزم ربطه بجدولة فعلية ووجهة تخزين مستقلة واختبار الاسترجاع دوريًا قبل استعماله تجاريًا.

## المبدأ
1. يُدقّق خادم Kasher قاعدة SQLite المحلية ويُنشئ لقطة متسقة مع WAL.
2. تُشفَّر اللقطة بمفتاح مشتق من كلمة مرور طويلة باستخدام AES-256-GCM.
3. يُعاد فك تشفير النسخة المحلية **مؤقتًا على الجهاز الموثوق**، ويُعاد تدقيق المستندات والدفاتر والأرصدة؛ إذا فشل التدقيق لا تُحذف النسخ القديمة.
4. عند تحديد وجهة ثانية، تنسخ أداة `offsite_backup.py` ملف النسخة **المشفّر فقط** إلى مجلد وجهة منفصل. لا يخرج أي SQLite غير مشفّر إلى هذه الوجهة.
5. تُقارن بصمة SHA-256 للنسخة الجديدة بالأصل، ثم تُختبر استعادتها من ملف الوجهة إلى مجلد مؤقت **محلي آمن** ويُدقّق المستعاد ثانيةً.
6. لا تُنشر النسخة باسمها النهائي ولا تُقلَّص النسخ القديمة في الوجهة إلا بعد نجاح **الاستعادة والتدقيق**؛ يمنع قفل حصري التزامن غير الآمن.

## الاستخدام من جهاز Windows الموثوق
من جذر المشروع، ثبّت الحزم:
```powershell
python -m pip install -r tools/requirements-backup.txt
```

جهّز هذه المجلدات مسبقًا بصلاحيات خاصة لحساب الخدمة، ويُفضَّل قرص Windows مشفرًا:
- `D:/KasherBackups`: النسخ المشفّرة المحلية.
- `D:/KasherScratch`: ملفات الاستعادة المؤقتة محليًا على جهاز الفرع.
- `\\BackupServer\KasherProtected`: وجهة تخزين مشفّرة وصلاحياتها مقيدة، ويجب أن تكون على جهاز/وسيط مستقل فعلاً عن خادم الفرع.

وفّر `KASHER_BACKUP_PASSWORD` أثناء تشغيل الأمر باستخدام خزنة أسرار موثوقة، **ولا تكتبها في ملفات PowerShell أو Git أو وسيطات سطر الأوامر**.

```powershell
python tools/scheduled_backup.py server/data/kasher.sqlite3 D:/KasherBackups --keep 14 --offsite-directory '\\BackupServer\KasherProtected' --scratch D:/KasherScratch --offsite-keep 30
```

النتيجة الناجحة ترجع JSON يحتوي على:
- `status: verified` للنسخة المحلية.
- `offsite.status: verified-offsite-copy` بعد قراءة الملف الخارجي وفكّه والتحقق منه.
- اسم النسخة المشفرة، الحجم، `sha256`، وعدد النسخ القديمة التي قلّصتها السياسة.

**في حالة انقطاع الشبكة أو فشل الوجهة:** يفشل الأمر بنتيجة غير صفرية، وتبقى النسخة المحلية التي تم التحقق منها محفوظة، ولا تُحذف النسخ المحلية القديمة بسبب فشل النقل. أصلح الاتصال ثم أعد إرسال الملف المحلي نفسه دون إنشاء نسخة جديدة:

```powershell
python tools/offsite_backup.py D:/KasherBackups/kasher-YYYYMMDDTHHMMSSZ-0123456789abcdef.kasherbak '\\BackupServer\KasherProtected' --scratch D:/KasherScratch --keep 30
```

## شروط التشغيل الآمن
- يجب أن تكون الوجهة **مستقلة فعليًا** (NAS/خادم نسخ خارجي أو وسيط منفصل) وليست مجلدًا ثانيًا على نفس قرص المتجر. الأداة لا يمكنها التأكد من الموقع الجغرافي للوجهة.
- احفظ كلمة المرور في مدير كلمات مرور خارج وسيط النسخ. ضياع كلمة المرور يعني عدم القدرة على فك التشفير.
- استخدم حساب خدمة له أقل صلاحيات ممكنة مع قائمة تحكم ACL؛ في Windows لا تتحقق الأداة آليًا من كل إعدادات ACL للشبكة.
- اضبط جدولة Windows Task Scheduler من إعدادات الخادم يدويًا، وشغّلها بحساب مقيد، وأضف مراقبة عند فشل المهمة. **الكود لا يثبّت مهمة مجدولة تلقائيًا**.
- نسّق نسخًا دورية مفصولة عن الجهاز وعلى وسيط غير قابل للتعديل من مشغّل كاشير عادي؛ سياسة القفل والتدوير البرمجية وحدها ليست حماية من برمجيات الفدية.
- اختبر استعادة شاملة على جهاز آخر **دون استبدال قاعدة حية** وأوقف الخادم قبل تبديل ملفات قاعدة البيانات. تحقق من أحدث المستندات والفروع والورديات والأرصدة.
- يجب تخزين النسخة الاحتياطية الفعليّة وملفات التحقق المشفّرة، ولا ترسل أي مفتاح أو كلمة مرور إلى GitHub.
- نسخ Google Drive عبر OAuth، ومراقبة جدولة النسخ والتنبيهات عبر خدمة قائمة، وتدريب الموظفين على الاستعادة ما زالت مهام غير مكتملة.

## اختبارات آلية مضافة
اختبار النسخ الخارجي بعد فك التشفير والتدقيق، ومنع حفظ نسخة تالفة، ورفض كلمة المرور الخاطئة، والحفاظ على قفل مهمة أخرى، والتحقق من الاحتفاظ بالنسخ القديمة وعدم تعديل النسخ المحلية، وإثبات بقاء النسخ المحلية الجيدة عند تعذر الوصول إلى الوجهة.

هذه اختبارات آلية؛ **ليست اختبار استعادة بعد عطل فعلي أو اعتماد خطة تعافٍ من الكوارث**.
