# ابدأ من هنا — كاشير السوبرماركت المصري

هذا **مشروع مصدر برمجي جاد قابل للاستكمال**، وليس نسخة تجارية جاهزة للاستخدام في متجر حقيقي. يحتوي على خادم محلي بـ Dart وقاعدة SQLite وتطبيق Flutter عربي لـ Windows وAndroid. **فحصنا SQL، لكن لم نستطع تشغيل Dart أو Flutter في بيئة إنشاء الملف** لعدم توفر SDK واتصال تنزيل الحزم.

## تشغيل تجريبي على Windows

1. ثبّت Flutter Stable وDart وVisual Studio مع أدوات Desktop C++ وAndroid SDK عند الحاجة.
2. افتح PowerShell داخل `server`، وابدأ إعداد المتجر:

```powershell
$env:KASHER_ADMIN_PASSWORD = Read-Host "كلمة مرور المدير (12 حرفًا على الأقل)"
dart pub get
dart run bin/kasher_server.dart --name="سوبرماركتي" --branch="الفرع الرئيسي" init
```

3. احفظ `tenant_id` الناتج، ثم شغّل الخادم:

```powershell
dart run bin/kasher_server.dart serve
```

4. داخل `app` نفّذ:

```powershell
flutter create --project-name kasher_app --platforms=windows,android .
flutter pub get
flutter run -d windows
```

5. اكتب عنوان الخادم `http://127.0.0.1:8787` ومعرف المنشأة واسم المستخدم `admin` وكلمة المرور التي اخترتها. لا توجد منتجات أو بيانات وهمية؛ أضف المنتجات والموردين ثم المشتريات قبل البيع.

6. لتشغيل هاتف Android على شبكة اختبار داخلية تحتاج ربطًا شبكيًا آمنًا. الخادم يستطيع الاستماع للشبكة مع `--bind=0.0.0.0` لكن **HTTP العادي ليس آمناً للإنتاج**، وقد يتطلب Android إعدادًا خاصًا لقبول الاتصال غير المشفر في وضع التطوير. لا تفتح المنفذ على الإنترنت.

## رفع ملفات المشروع إلى GitHub

المستودع المستهدف هو `https://github.com/jjBurgur/Kasher`. اتصال GitHub الذي كان متاحًا أثناء الإعداد **للقراءة فقط**، لذلك لم تُرفع إليه الملفات. بعد تنزيل ZIP وفك ضغطه، وبحساب GitHub لديه صلاحية كتابة، شغّل:

```powershell
.\scripts\publish_branch.ps1
```

سينشئ السكربت فرعًا جديدًا ويرفع التغييرات دون لمس `main` مباشرة. أنشئ Pull Request وراجع فحوصات CI قبل الدمج. إذا لم تكن لديك صلاحية كتابة، اطلب من مالك المستودع منحها لحساب GitHub الذي تستخدمه.

## ما الذي لا يزال ناقصًا؟

ربط الميزان والطابعات، الترخيص السنوي المؤمَّن، النسخ الاحتياطي المشفّر، المزامنة السحابية، التشغيلات والصلاحية الكاملة، الربط الضريبي الرسمي، الفروع المنفصلة وتبادل المخزون، اعتماد الاختبارات الـ34، وحزم تثبيت مختبرة. القائمة التفصيلية في `docs/IMPLEMENTATION_STATUS.md`.
